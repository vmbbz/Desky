Security

XEON Protocol (Pty) Ltd · security@deskii.app

Do not report vulnerabilities by regular email or public issue trackers. Send all reports to security@deskii.app. We acknowledge within 3 business days.

Reporting a vulnerability

  1. Email security@deskii.app with a clear description of the issue.
  2. Include steps to reproduce, affected version(s), and potential impact.
  3. Provide your contact details so we can follow up.
  4. Give us reasonable time to investigate and remediate before public disclosure.

We acknowledge within 3 business days and aim to provide an initial assessment within 10 business days.

Safe-harbour commitment

We will not pursue legal action against researchers who report privately before public disclosure, do not access or destroy user data beyond what is necessary to demonstrate the issue, and do not disrupt production services or act for financial gain.

Scope

In scope: Deskii desktop app (Windows, current release), agent credential storage and IPC isolation, tool-call approval boundary, deskii.app website and hosted checkout, Supabase-backed account services.

Out of scope: The AI agent services you connect (report to their maintainers), social engineering, physical attacks, denial-of-service, issues in third-party libraries already publicly known.

Security design principles

  • Process isolation: Agent credentials live in the Electron main process only and are never exposed to the renderer.
  • Tool approval gates: Every agent tool call requiring filesystem, code execution, or network access requires explicit user approval.
  • No private key access: Wallet operations are signed by MetaMask on the user's device; Deskii never receives signing keys.
  • Strict CSP: The renderer operates under a strict Content Security Policy.
  • Sandboxed renderer: contextIsolation: true and nodeIntegration: false.

Supported versions

Only the current release version of Deskii receives security updates. Keep Deskii updated via the Microsoft Store or direct-download channel.

Bug bounty

We do not currently operate a paid bounty programme. We acknowledge researchers with their permission in release notes.
