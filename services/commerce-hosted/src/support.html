What is Deskii?

Deskii is a desktop companion application for Windows. It provides an expressive animated avatar and interface for AI agent services you connect — such as OpenClaw, Codex, or Hermes. Deskii does not include a built-in AI model; it is an interface for the agents you already use.

System requirements

  • Windows 10 version 1903 or later (64-bit)
  • 4 GB RAM minimum, 8 GB recommended
  • GPU with DirectX 11 support for avatar rendering
  • Internet connection to reach your chosen agent service
  • An account or API key for at least one supported agent (OpenClaw, Codex, or Hermes)

Getting started

  1. Download and install Deskii from the Microsoft Store.
  2. Launch Deskii — the avatar companion appears on your desktop.
  3. Click the ⚙ icon to open the Control Center.
  4. Select your agent type and enter your connection details.
  5. Click Connect. Once connected, type or speak to start a conversation.

Voice conversations

Voice requires an agent connection that supports real-time audio (OpenClaw with a voice-capable model). Click the microphone icon in the companion, speak naturally, and click Stop to end the session.

Troubleshooting

Deskii says "Not connected"

Check your gateway URL and credentials in the Control Center. Verify the agent service is running and reachable. For OpenClaw, ensure the gateway process is started.

Avatar shows a loading state or error

Deskii downloads avatar assets on first launch. Ensure you have an internet connection and at least 500 MB free disk space. Click the avatar and choose Reload from the tooltip.

Voice session connects but no audio

Check your Windows audio output device. Verify your chosen agent model supports audio output — not all configurations support voice.

Agent tool calls are not executing

Deskii requires explicit approval for every tool call. Check the amber approval prompt in the companion or Control Center. Dismissed approvals timeout and the agent is notified.

Reporting inappropriate AI output

If the connected agent produces harmful or policy-violating content, please use our AI content report form.
